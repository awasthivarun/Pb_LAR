# Pb LAR DFT Project

Source and provenance repository for Pb-catalyzed levulinic acid reduction calculations.

## Directory roles

- `ase_workbench.ipynb`: structure construction and calculation setup notebook.
- `analysis/`: analysis and classification utilities.
- `scripts/`: reusable calculation/setup utilities.
- `control/`: canonical JDFTx/pyjdftx calculation templates.

Large generated calculations are not stored in this repository.

Calculation output root:

    /pscratch/sd/a/awasthi/Pb_LAR

Source repository:

    /pscratch/sd/a/awasthi/Pb_LAR_source

The calculation directory is considered regenerable from this repository plus recorded metadata.
